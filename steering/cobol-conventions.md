## Indicator 慣例分類

| 範圍 | 用途 |
|------|------|
| 01-24 | 功能鍵（F1-F24），03=離開 04=提示 05=重整 06=新增 12=返回 |
| 25-30 | 特殊控制鍵（HELP, HOME） |
| 31-56 | 欄位驗證指標（Reverse Image / Position Cursor） |
| 81-89 | 程式模式控制（81=新增/修改模式, 83=保護, 85=訊息） |
| 90-99 | SFL 控制（90=初始化, 92=清除, 93=顯示, 94=下次變更） |
